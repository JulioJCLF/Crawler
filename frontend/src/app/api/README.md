# Frontend API

## Overview
Next.js App Router API subsystem grouping health monitoring, pricing management, catalog queries, user authentication, and administrative controls.

## Subdirectories & Boundaries
- [admin](./admin/README.md): Administrative catalog modification, item hiding, and cache clearing.
- [auth](./auth/README.md): Authentication endpoints covering login, logout, session check, and password reset.
- [health](./health/README.md): Health-check and liveness inspection route.
- [pricing](./pricing/README.md): Dynamic currency conversion and category markup endpoints.
- [products](./products/README.md): Public storefront product catalog query endpoint.
