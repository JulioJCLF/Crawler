# Admin Catalog API

## Overview
Catalog management API routes providing item visibility control, custom product CRUD, and server cache invalidation.

## Subdirectories & Boundaries
- [products](./products/README.md): Admin product listing and custom inventory CRUD operations.
- [hide](./hide/README.md): Product visibility suppression from public storefront.
- [unhide](./unhide/README.md): Restoring hidden product visibility.
- [reset-cache](./reset-cache/README.md): Immediate server catalog cache reset and reload.
