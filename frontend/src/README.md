# Frontend Source Core

## Overview
Core Next.js application codebase encompassing App Router layouts, presentation components, context state providers, domain services, and TypeScript contracts.

## Subdirectories & Boundaries
- [app](./app/README.md): Next.js App Router shell, storefront homepage, administrative dashboard, and API endpoints.
- [components](./components/README.md): Product cards, interactive filters, hero banner, radar changelog, cart drawer, and UI primitives.
- [config](./config/README.md): Global site settings, theme palettes, and routing base paths.
- [lib](./lib/README.md): Pricing calculations, string sanitization, catalog services, authentication, and search utilities.
- [providers](./providers/README.md): React context providers for shopping cart, dynamic pricing, and UI theming.
- [types](./types/README.md): Core TypeScript data models, contracts, and role definitions.
